# Placement / hover / crate follow-up

Latest incremental user feedback, after the initial occupancy-completion pass.

## Placement colors

`FootprintPlaceBuildingPreviewPreview` distinguishes physical movement masks from
placement validity. Valid `=` and `+` cells use `build-valid-passable`: pale green
RGB144/255/144,55% of the normal marker opacity. Valid `x`/`X` cells keep the original
strong green. Invalid always wins and remains red, including invalid bib cells.
Empty/unknown cells and line-build markers do not become pale green. Negative
Location-relative footprint keys are honored.

The optional sequence applies to footprint, sequence and actor previews through the
shared preview implementation. If absent in another mod, the old rendering remains.
Scale2, ZOffset4096 and the foreground placement layer are retained.

**No new PNG is required at runtime.** The sequence reuses `build-valid-iso.png`;
`TintModifiers.ReplaceColor` changes only rendered RGB, retaining its alpha silhouette.
The initially created `build-passable-iso.png` prototype is not referenced, and remains
on disk so an already-running process with an older cached sequence is not broken by
removing it. The original green/red assets are untouched. A review-only legend is
`art-source/placement-followup/marker-legend.png`.

The user hit FileNotFoundException while the new sequence/file was being introduced.
The binding now has no additional file dependency. Full default SequenceSet.LoadSprites
has subsequently passed, not merely a file-existence check.
